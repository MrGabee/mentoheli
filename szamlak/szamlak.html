❓ Fel nem ismert levelek

A mentéshez egy GitHub Personal Access Token szükséges (a repóhoz írási joggal) - ez csak a böngésződben marad (a jelszóhoz hasonlóan, session-tárolóban), a mentés közvetlenül innen, a böngésződből megy a GitHub API-nak, sehova máshova nem kerül.

Itt állíthatsz be egy MÁSODIK, rövidebb jelszót valakinek, aki csak megnézni szeretné a számlákat. Ez technikailag NEM egy külön, "megszűrt" adatállapot (az adatok titkosítási módja nem változik) - a te (admin) jelszavad kerül becsomagolva, ÚJRA titkosítva ezzel a felhasználói jelszóval eltárolásra, hogy a felhasználói jelszóval megnyitva a böngésző ki tudja csomagolni és onnantól ugyanúgy hozzáférjen a (visszafejtett) adathoz, mint te - a felület viszont "user" szerepkörben elrejti előle az admin-csak szekciókat (Beállítások, Bérlői körök, Címzettek és azonnali küldés, dátum szerinti küldés, a táblázat "Kör" oszlopa és a "✕" végleges-elrejtés gomb).

🔐 Admin jelszó módosítása

Ez a saját (admin) jelszavad - ez titkosítja/fejti vissza a teljes számla-adatot. Módosítás után az ÖSSZES jelenlegi adatot újratitkosítjuk az új jelszóval (semmi nem törlődik) - DE ezután a GitHub repo SZAMLA_TITKOSITAS_JELSZO Secretjét (Settings → Secrets and variables → Actions) is UGYANERRE az új jelszóra kell írnod, különben a legközelebbi automatikus (Action) futás nem fogja tudni visszafejteni az adatot, és hibával fog leállni.

A Díjneten/Vízműveken érkező számlákat két bérlői körhöz sorolhatod - mindkettő saját email-címre kap "új számla" értesítőt (PDF-fel) és havi összesítőt. A besorolás a titkosított adatban tárolódik (nem publikus), ehhez is a fenti GitHub token + a megnyitáshoz használt jelszó kell (ez utóbbi csak a böngésződben marad).

A bérlői körök (és a tulajdonos/könyvelő) email-CÍMLISTÁIT és az azonnali "Küldés most" gombokat lentebb, a "📮 Címzettek és azonnali küldés" panelben találod. A régi, egy-cím-es GitHub Secretek (SZAMLA_KOR_A_EMAIL / SZAMLA_KOR_B_EMAIL) - ha még be vannak állítva - továbbra is UNIÓBAN kapnak emailt az itt/lent megadott listával.

⏳ Függőben lévő Díjnet-kibocsátók

Ezekről a kibocsátókról már van rögzített számla, de még nincs bérlői körbe sorolva - amíg itt be nem sorolod, NEM megy ki róluk értesítő email.

✅ Már besorolt Díjnet-kibocsátók

Három, egymástól független email-kör: a könyvelő SOSEM kap innen számla-adatot/csatolmányt - a tulajdonos azt egy külön, kézzel megosztott Google Drive mappán keresztül adja át neki, ő csak egy havi, hónap-végi emlékeztetőt kap. A bérlő (1./2. kör) a jelenleg fizetetlen számláinak időszakos/kézi összesítőjét kapja - NEM azonnali, számlánkénti értesítőt. A tulajdonos minden új számláról azonnali értesítést kap, és minden bérlői-összesítő másolatát is megkapja. Soronként egy email-cím - a mentéshez/küldéshez a fenti GitHub token kell.

🏠 Tulajdonos

A megadott fizetési határidő-intervallumba eső számlákat PDF-csatolmánnyal elküldi a megadott címre. A küldés a GitHub Actions-ön keresztül indul, néhány percen belül lefut - ehhez is a fenti GitHub token kell.

Itt adhatsz hozzá TETSZŐLEGES SZÁMÚ, a fenti fő postafiókodtól FÜGGETLEN email-fiókot, amit a script mostantól FOLYAMATOSAN (minden futásnál) figyel: minden PDF-csatolmányos levelet megvizsgál, hogy az valóban számla-e (a levél/PDF TARTALMA alapján, nem a feladó címe alapján). A "Cél" választja el, hogy a felismert számlák a Közüzemi listába kerüljenek-e (a lent megadott "címke" alatt, pl. "Csatornázási Művek"), VAGY a Céges számlák fülre (mintha a dedikált céges postafiókból jöttek volna) - utóbbit akkor válaszd, ha ez a postafiók ténylegesen céges beszerzési számlákat gyűjt. A megadott jelszó mentés előtt TITKOSÍTVA kerül a GitHub-ra, ugyanúgy, mint minden más adat itt.

➕ Gmail-postafiók hozzáadása (App Password)

A Gmail-fiókodon be kell kapcsolnod a kétlépéses azonosítást (Google-fiók → Biztonság), utána a Biztonság → Alkalmazásjelszavak menüben tudsz generálni egy 16 karakteres kódot ("Mail" típusra) - NE a sima Gmail-jelszavadat add meg alább, csak ezt a kódot.

Ide kerülnek azok a számlák, amiket a cég nevében történő vásárláskor kérsz el emailben az eladótól, a dedikált céges email-címre. A postafiókot a script rendszeresen ellenőrzi: minden PDF-csatolmányos levelet feltölt a Google Drive-ra ("Céges számlák" mappa, eladónkénti almappákkal), majd - hogy ne fogyjon a postafiók tárhelye - a levelet onnan véglegesen törli. Emiatt itt lent NEM egy letöltés-gomb van, hanem egy "Megnyitás Drive-on" link.

A fent listázott (email-ből begyűjtött), ILLETVE a Közüzemi fülön lévő számlákat is a script minden futáskor összeveti a NAV Online Számla rendszerben, a cég adószámára nyilvántartott bejövő számlákkal - ez a Céges táblázat "NAV-párosítás" oszlopában látszik. Ha a NAV-on van egy számla, ami emailben SOHA nem érkezett meg egyik figyelt postafiókba sem, az itt lent, egy külön listában jelenik meg szállítónként csoportosítva - itt email-címet adhatsz meg a szállítóhoz, kijelölheted, majd egy sablon-szövegű emlékeztetőt küldhetsz neki, amiben megkéred, küldje el a számla másolatát.
